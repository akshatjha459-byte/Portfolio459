CloudAWSProject-101

github.com/akshatjha459-byte/CloudAWSProject-101

A hybrid-cloud file synchronization system built with a FastAPI backend and AWS infrastructure. Designed with modular architecture, storage/metadata abstractions, and synchronization logic.

Architecture

  • 10-module structure separating concerns: local filesystem, filesystem watching, change detection, sync orchestration, API layer, AWS integration, bidirectional sync, conflict resolution, observability, and dashboard
  • Adapter pattern for storage and metadata backends—swap between in-memory (development) and AWS S3 / PostgreSQL RDS (production)
  • SHA-256 hashing for reliable change detection
  • Built-in observability layer for monitoring and alerting

Technology

  • FastAPI, Python, Uvicorn
  • AWS S3 (object storage), EC2 (compute), RDS (PostgreSQL)
  • Docker, SQLAlchemy, boto3
  • REST API, filesystem watchers, automated testing

Key Engineering Decisions

  • Environment-driven configuration via .env for portability—no hardcoded paths or credentials
  • Application factory pattern in FastAPI for clean testability and dependency injection
  • Separation of concerns: adapters, services, routes, and infrastructure are independently maintainable
  • Static dashboard mounted directly within the FastAPI application
