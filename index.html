CloudAWSProject-101

github.com/akshatjha459-byte/CloudAWSProject-101

A hybrid-cloud file synchronization system. A FastAPI backend coordinates file watching, change detection, and sync logic, with AWS handling object storage and compute.

What it does

  • Tracks a local filesystem, detects changes with SHA-256 hashing, and syncs files to AWS S3 through a modular pipeline

How it's built

  • 10-module architecture: filesystem watching, change detection, sync orchestration, API layer, AWS integration, bidirectional sync, conflict resolution, observability, and dashboard
  • Adapter pattern for storage and metadata backends—in-memory for development, S3 plus PostgreSQL RDS for production

Engineering choices

  • Environment-driven configuration via .env for portability
  • FastAPI application factory for clean testability
  • Separation of adapters, services, routes, and infrastructure
